# BUYCHEY – Multi-Vendor E-Commerce Platform with WhatsApp-Based Ordering

BUYCHEY is a modern multi-vendor e-commerce platform designed to simplify online selling and buying. It enables vendors to manage products easily while allowing customers to place orders via a web interface or WhatsApp, making digital commerce accessible to everyone.


## 📌 Project Overview
**Goal:** Build a scalable multi-vendor marketplace with WhatsApp-based ordering.  
**Approach:** Combine web-based shopping with conversational commerce using APIs.  
**Target Users:** Small vendors, non-technical users, and customers.  
**Outcome:** A platform where users can browse, order, and manage products seamlessly.

---

## ⚙️ Features
- Vendor registration and product management  
- Multi-vendor product listing system  
- Automated order splitting (vendor-wise)  
- WhatsApp-based ordering (planned)  
- Secure payment and order management system  
- User-friendly interface for customers and vendors  

---

## 🛠️ Tech Stack
